# goignore - `.gitignore` generator

## Installation

```bash
go install github.com/zeindevs/goignore@latest
```

Download:

- <https://github.com/zeindevs/goignore/releases>

## Usage

```sh
goignore [lang]
```

Example:

```bash
goignore go
goignore cpp
```

Lang available:
- c
- cpp
- go
- node
- python
